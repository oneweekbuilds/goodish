# Screen Recording Guide for AlgorithmLens Audit

## How to Record

1. On your iPhone, open Control Center and tap the Screen Recording button
2. Wait for the 3-second countdown
3. Follow the walkthrough below systematically
4. When done, tap the red status bar at the top to stop recording
5. Send the recording to your laptop via email or Messages

## What to Capture — Full Walkthrough

Go through this checklist IN ORDER so the auditor can follow along:

### 1. App Launch (5-10 seconds)
- Cold-start the app (swipe it away first, then reopen)
- Wait on the home/landing screen for a few seconds

### 2. Main Feed / Dashboard (15-20 seconds)
- Scroll through the main feed slowly
- Pause on each analysis card/result for 2-3 seconds
- Scroll back to the top

### 3. Each Analysis Dimension (30-60 seconds)
- Tap into each of the six analysis dimensions
- Let each one fully load
- Scroll through the results
- Go back to the main screen between each

### 4. Live Broadcast Feature (15-20 seconds)
- Navigate to the live broadcast feature
- Tap to start a broadcast
- Record whatever happens (error, blank screen, success)
- Try to go back to the main app

### 5. Subscription / Paid Version (15-20 seconds)
- Navigate to the upgrade/subscription area
- Tap on the subscribe/upgrade button
- Record whatever happens (error, spinner, payment screen)
- Try to go back

### 6. Settings / Profile (10 seconds)
- Open settings if available
- Scroll through any options

### 7. Edge Cases (10-15 seconds)
- Pull to refresh on the main feed
- Rotate the phone (if the app supports it)
- Tap rapidly on a button to test responsiveness
- Navigate back and forth quickly between screens

### Total Expected Duration: 2-3 minutes

## Tips for Good Recordings

- **Go slow.** Pause for 2-3 seconds on each screen so frames are clear
- **Show everything.** Even if something looks fine, record it — the auditor
  needs to verify working features too, not just broken ones
- **Don't skip the broken parts.** If something errors, record the error.
  If something spins forever, record 5-10 seconds of spinning.
- **Full brightness.** Ensure screen is at max brightness for clear frames
- **No notifications.** Turn on Do Not Disturb to avoid notification banners
  covering the app during recording
