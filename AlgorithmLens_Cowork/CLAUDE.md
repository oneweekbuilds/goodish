# AlgorithmLens - Folder Instructions

## About This Project
AlgorithmLens is a consumer AI transparency tool. It is a React/Vite frontend with a Python backend.

## Working With Me (Justin)

- Never make changes to any files without explicitly asking me first and getting my approval.

## Architecture
- **Frontend:** React + Vite
- **Backend:** Python
- **Payments:** Stripe (the `is_user_plus` flag in the database gates premium features)
- **Dashboard Tabs:** Overview, Sources, Ads, Politics, Tone, Suggested vs Followed

## Pricing Model
- Freemium: free scans for all users
- Plus tier: $10/month or $96/year
- Plus users get longitudinal trend analysis
- Two-week free trial included
