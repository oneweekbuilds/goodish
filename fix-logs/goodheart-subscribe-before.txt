- Dev server: http://localhost:3000
- Issue: Quiz email-gate modal showing "Failed to fetch" error

1. GoodHeart uses SubscribeModalGoodHeart component (components/SubscribeModalGoodHeart.tsx)

Goodish Working Flow (for comparison):

Root Cause Hypothesis:
- GoodHeart uses iframe embed which can fail due to CSP frame-src restrictions

- GoodHeart may be missing proper CSP configuration for Beehiiv domains
